PSX House Key
=============

Authentic PS1-style low-poly game asset.

Triangles: 60
Objects: house_key (60 tris)
Size: 0.09 x 0.02 x 0.00 m (real-world scale, 1 unit = 1 metre)
Texture: 64x64 px, 18 colours, one atlas (textures/psx_house_key_diffuse.png)
Use nearest-neighbour ("point") filtering and no mipmaps for the authentic look.
Pivot: bottom centre.
Axes: FBX/OBJ are Y-up, -Z forward (Unity / Unreal / Godot ready). GLB follows glTF conventions.

Files:
  psx_house_key.fbx
  psx_house_key.obj
  psx_house_key.mtl
  psx_house_key.glb
  collision/psx_house_key_collision.fbx
  psx_house_key.blend
  textures/psx_house_key_diffuse.png

collision/ holds a simple convex collision mesh (UCX_ prefix = Unreal custom collision).
